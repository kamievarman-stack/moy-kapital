МОЙ КАПИТАЛ — ПЛАНИРОВЩИК ПАССИВНОГО ДОХОДА, версия 1.0

ФАЙЛЫ:
index.html             — само приложение, можно открыть на компьютере в браузере
manifest.webmanifest   — установка приложения на Android (PWA)
sw.js                  — офлайн-режим
icon-192.png           — иконка
icon-512.png           — иконка

УСТАНОВКА НА ANDROID (аналогично приложению "Моя зарплата"):
1. Создать новый публичный репозиторий на github.com, например moy-kapital.
2. Загрузить все 5 файлов в корень репозитория. НЕ используйте репозиторий "moya-zarplata" — это отдельное приложение.
3. Settings -> Pages -> Build and deployment -> Deploy from a branch -> main / (root) -> Save.
4. Открыть опубликованную ссылку вида https://<логин>.github.io/moy-kapital/
5. В Chrome на телефоне нажать меню -> "Установить приложение" или "Добавить на главный экран".
6. После первой загрузки через HTTPS приложение способно работать офлайн.

ДАННЫЕ И БЕЗОПАСНОСТЬ:
- Все финансовые данные хранятся локально в браузере, не отправляются на GitHub.
- GitHub получает только файлы программы, если вы разместите её на GitHub Pages.
- Сохраните резервный архив JSON в разделе «Настройки»; чистка данных Chrome/смена телефона может стереть локальный архив.
- PIN блокирует интерфейс, но не шифрует localStorage и JSON.
- Процентный прогноз — модель с постоянной ставкой (годовая ставка / 12), не гарантированная доходность.
- Режим "Фиксированный доход" предполагает ежемесячную выплату.
- Приложение не связано с банками и не собирает данные автоматически.

ОБНОВЛЕНИЕ:
- Заменить index.html новым файлом, и при изменениях офлайн-режима изменить версию CACHE в sw.js.
- Обновление файлов не должно стирать localStorage, но резервная копия обязательна.
